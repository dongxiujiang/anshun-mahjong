# 音频素材

全部文件随 Godot 导入，可在 PC/Android 离线播放。运行时不使用 Windows 语音服务，也不使用 Python。

| 用途 | 文件 | 来源 |
| --- | --- | --- |
| 背景音乐 | `music/table.wav` | Kevin MacLeod《Ripples》，目录描述为舒缓的中国古筝/拨弦风格，57 BPM，约 205 秒；经淡入淡出、低响度处理后循环播放 |
| 出牌语音 | `voice/*.wav`、`voice/seat1/*.wav`–`seat3/*.wav` | 四套不同的 Microsoft Edge 普通话声音（两女两男），放慢语速并柔化高频；一条使用「幺鸡」 |
| 碰/杠/报听/胡/自摸 | 每个座位目录中的 `pong.wav`、`kong.wav`、`ready.wav`、`hu.wav`、`zimo.wav` | 与该座位相同的声音；明杠、暗杠、加杠喊「杠」，胡别人或抢杠喊「胡了」 |
| 落桌音效 | `effects/discard.wav` | 原创程序生成双次落桌声，约 0.24 秒 |

所有 WAV 为 22.05 kHz、16-bit 单声道。四个座位共 128 段语音，已去掉多余空白、统一较柔和的音量，并淡入淡出以避免点击；每段小于一秒，适配快档 AI。`manifest.json` 记录来源、声音列表和每段长度。声音设置中可试听四套声音。

替换音频：保留文件名，使用自己的录音或有使用权的音乐覆盖文件，等待 Godot 自动导入后重新运行。支持同名 OGG/WAV/MP3，优先加载 OGG，其次 WAV，再其次 MP3；建议同一音频只留一种格式。音乐自动循环，语音自动关闭循环；音效请关闭导入选项中的循环。

可选重新生成：Python 安装 `numpy`、`edge-tts`、`imageio-ffmpeg` 后，运行 `tools/audio/generate_audio.ps1 -PythonPath <python.exe的路径>`。神经语音生成时需要联网，全套生成成功才覆盖已有语音；可以通过 `-DependencyDirectory <目录>` 使用独立安装的依赖。背景音乐使用已授权的《Ripples》素材，不会被语音生成脚本覆盖。玩家无需安装这些工具、也无需联网。

若仅有 Windows 简体中文 SAPI 语音包及 Python/NumPy，可以加 `-VoiceSource Local` 生成慢速本地女声作为备用；声音自然度低于随工程提供的神经语音。

声音面板默认音乐 12%、语音 80%、音效 65%；三项开关和音量独立保存。升级时旧默认值会调低，已经手动调整的值保留。喊牌时音乐再降低约 11 dB，语音结束恢复。积压的牌名不会挤掉碰、杠、报听，胡牌和自摸优先清掉旧语音。安卓切后台暂停音乐和语音，回到前台继续音乐。
