# V1.6.28

- 四个方位的杠牌按模型实际尺寸贴合，修复杠对家牌时第四张横牌分离和宽屏间距偏大的问题，保留明杠来源方向。
- 将牌桌、麻将和骰子升级为真实 3D 模型，优化安卓横屏下的镜头、牌面清晰度和四家手牌透视。
- 南北普通弃牌每行 10 张、最多 3 行；东西每行 8 张、最多 4 行。相邻行按真实模型贴合，靠近镜头的牌遮住远处牌的底边。
- 优化碰杠和幺鸡八筒的位置、庄家及报听标记、玩家姓名与分数；最新弃牌使用立体三角标记。
- 结算时手牌平铺，准备下一局和下一局按钮放在手牌下方，只允许覆盖牌底座。
- 排序按钮横排移到牌桌右下角，只允许覆盖手牌底部；修复多组碰杠时的操作按钮遮挡、短手牌遮住边家鸡牌，以及恢复同一牌局快照时碰杠区跳位。
- 包含上一候选版的手牌双向排序、听张与牌型推荐优化，以及主页和房间操作简化。

本次为完整 Android 安装包，可覆盖安装并保留原有设置。玩法、计分和联机协议保持兼容。
