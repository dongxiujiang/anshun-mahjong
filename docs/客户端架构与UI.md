# 客户端架构与 UI 说明（v2.4.0）

客户端基于 **Godot 4.7.2（GL Compatibility 渲染后端）** 构建，面向 Android 横屏手机/平板与 Windows 桌面，工程位于 `remake/game/`。

---

## 一、界面流程与新中式视觉设计

全局统一采用**深黛墨玉底色 + 古铜描金边框 + 宣纸象牙牌面**的新中式茶馆风格（`AppTheme.gd`、`AppBackdrop.gd`、`TableTheme.gd`）：

1. **首次入局资料页（`ProfileSetup.gd`）**：15 位原创立绘人物两行横向滑动选择、自定义/随机昵称，支持手机端返回键失焦与防误退二次确认。
2. **茶馆主大厅（`Main.gd`、`RoomBrowser.gd`）**：双栏布局——左侧聚合单机开局、局域网约局与在线开桌 2×2 工具箱；右侧展示实时 3D 房间台面，顶部提供战绩、资料、设置入口。
3. **等待房间（`Main.gd`）**：东西南北四向罗盘选座，展示玩家头像、准备状态与局域网连接地址，人齐准备后无需多余倒计时直接开局。
4. **2.5D 实感牌桌（`TableView.gd`）**：
   - `camera_pitch = 45.4°`，本家手牌放大 `1.82×`（`self_hand_pitch = 66°`），支持双击/上滑出牌、拖拽理牌与一键智能排序/恢复排序。
   - 仅在轮到本家操作时显示固定位置的圆形倒计时钟（`TurnClockView.gd`），移除牌桌 3D 庄/听立牌摆件。
5. **固定居中结算页（`SettlementView.gd`、`SettlementNames.gd`）**：首帧精确居中于牌墙内安全区，移动端底部提供 `[离开]`、`[查看牌面]`、`[下一局]` 操作栏；结算明细中的冲锋鸡/冲锋金鸡横置对齐牌桌朝向，四家名片同步显示 `[庄]`/`[听]` 印章。

## 二、局内辅助、语音与遥测功能

| 模块 | 源码 | 核心行为 |
| --- | --- | --- |
| **常驻叫牌与抬牌计数** | `src/app/TingAssistantOverlay.gd` | `听牌中 / 报听中` 固定显示在底左本家名片正上方，摸牌/出牌持续不消失、换听实时更新；抬起手牌仅在牌顶显示 `X · 已出 Y 张`（仅计场上弃牌与可见碰杠）并高亮同牌。 |
| **名片角色印章与语音状态** | `src/app/PlayerBadge.gd` | 名称旁显示红金 `[庄]`、翠玉 `[听]` 印章；联机房真人分数旁固定展示 `麦开 / 麦关`（本家）及 `发言中 / 收听中 / 已静音`（他家真人），AI 座位与单机模式保持纯净；点击名片切换并弹出顶部 Toast 提示。 |
| **实时 FPS 与网络延迟** | `src/app/StatusTelemetryBar.gd`、`src/network/GameClient.gd` | 常驻安全区右上角空白区（宽屏单行、窄屏双行，零遮挡），2 Hz 平滑刷新 FPS；局域网/在线服务器基于 ENet 传输层 `PEER_LAST_ROUND_TRIP_TIME` 实时显示连接状态点与毫秒延迟（<60ms 绿 / 60–149ms 金 / ≥150ms 红，以及连接中/重连中/已断开）。 |
| **战绩与图鉴** | `src/app/CareerPanel.gd`、`PlayerProgress.gd` | 本地统计胜率、连胜、段位与冲锋鸡/大牌图鉴解锁。 |

## 三、v2.4.0 全链路性能优化

1. **角色立绘显存与体积优化**：15 张立绘由 `1086×1448`（23.69 MB，~94 MB 显存）经 Lanczos 重采样至视网膜级 `384×512`（3.05 MB，~11 MB 显存），APK 体积减少 **21+ MB**（至 85.84 MB），Android 冷启动降至 **1.96 秒**。
2. **冷启动按需加载**：`TileArt.gd` 改为按需懒提取单张牌面 UV 并缓存横置牌面；`SoundStage.gd` 优先加载 Godot 预导入二进制音频并在静默期自动关闭 `_process`。
3. **零无效 3D 渲染**：菜单/大厅界面关闭牌桌 3D `SubViewport`（`UPDATE_DISABLED`）；`RoomBrowser` 空房间时关闭 3D 视口、有房按需 `UPDATE_ONCE`；牌桌 `ReflectionProbe` 改为 `UPDATE_ONCE`。
4. **消除逐帧分配与冗余网格**：复用落牌涟漪网格、缓存手牌基准锚点、`WinFeedback` 预缓存 `StyleBoxFlat`、`DiceRoll` 静态缓存轻量化骰子网格、`StatusTelemetryBar` 数值不变零重绘。
