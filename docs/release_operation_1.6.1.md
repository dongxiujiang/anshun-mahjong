# 1.6.1 发布与部署记录

版本：`1.6.1`  
Android versionCode：`62`  
构建日期：2026-10-27

## 本版内容

- 中档 AI 重做危险牌模型：
  - 用 122,024 条实际听牌牌张样本训练 tile-wait 概率；
  - 中档使用该模型替换原对手风险分布；
  - 牌墙后段高威胁时增加公共安全牌筛选；
  - 优化 wait 模型计算，避免明显增加思考时间。
- 设置中的中档 AI 可正式选择；
- 新安装默认中档；专用服务器默认中档；
- 高档仍暂时禁用。

## 2000 局基准

两组独立种子，共 4000 局：

```text
低档：胜率 25.15%，均分 1.6195，平均 74.14ms
中档：胜率 25.30%，均分 1.8930，平均 74.97ms
```

两组方向一致：

```text
第一组：26.1%→26.2%，1.870→2.336
第二组：24.2%→24.4%，1.369→1.450
```

说明：平均耗时低于 100ms；P95 仍在 250ms 左右，得分差置信区间包含 0，属于方向一致而非强统计显著。
