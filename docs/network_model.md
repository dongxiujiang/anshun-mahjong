# 联机网络模型

麻将是回合制游戏，本项目采用“状态同步 + 权威端校验”，不采用帧同步。局域网房主和云端 Godot 房间服务器都承担同一类权威职责；客户端只提交操作意图，不能直接修改牌局。

权威端负责洗牌、骰子、破墙、摸牌、判胡、碰杠胡窗口、结算、庄家和下一局状态。客户端提交出牌、碰、杠、胡、报听、准备、选座和换座请求。请求带座位号与 `prompt_id`，服务器会检查发送者是否拥有该座位、当前提示是否仍有效、操作是否符合规则，然后只广播新的完整状态快照。

快照通过 ENet 可靠通道发送，并带递增 `revision` 和 `round_number`。客户端丢包或乱序时丢弃旧 revision；状态更新合并在一帧内发送，避免同一动作触发多次重复刷新。音效事件带每局 session 和事件编号，重连不会重复播放历史语音。

## 断线与重连

玩家加入时生成 `resume_token`。游戏开始后掉线，权威端保留该座位、昵称、准备状态和 token 30 秒，并由 AI 暂代该座位；掉线玩家在保留期内使用同一 token 重新连接，会恢复原座位、手牌、分数和当前提示。恢复成功前客户端不允许提交新操作，收到最新快照后才解除锁定。超过 30 秒仍未回来，座位才会释放为人机。

房主关闭局域网房间时，房间随主机结束；云端房间可继续运行。重连失败不会清空本地界面，客户端会显示重试进度，最终提示返回房间列表重新加入。网络连接只需要房间地址和端口，局域网模式通过发现服务自动得到地址，不要求玩家输入 IP。

## 玩家名称

创建或加入房间前每位真人输入自己的昵称，长度限制为 16 个字符。权威端保存昵称并在等待页和牌桌快照中同步；牌桌四个座位显示真实昵称，人机显示“人机 1”等。昵称只用于当前房间，不作为账号或身份验证。

## 云端部署边界

云端目录服务只负责列出房间和连接地址，牌局仍由房主或专用 Godot 房间服务器权威处理。生产环境应让客户端只连接权威房间端口，并在目录服务上设置房间过期时间、连接数限制和心跳监控。详细启动方式见 [server/README.md](../server/README.md)。
