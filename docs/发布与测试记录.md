# 发布与测试记录

## v2.4.0（2026-11-27 · Build 7）

### 版本变更摘要

1. **听牌常驻与抬牌精简提示**：`听牌中 / 报听中` 常驻玩家名片上方，摸牌/出牌不消失、换听实时更新；取消牌桌中央出牌建议弹窗，抬牌仅显示场上已出张数。
2. **牌桌标记清理**：移除牌桌 3D 庄家/报听立体摆件，对局与结算名片旁统一展示 `[庄]`、`[听]` 印章。
3. **结算页冲锋鸡横置对齐**：冲锋鸡与冲锋金鸡在结算明细中采用逆时针 90° 横置金边牌面，与 3D 牌桌实体朝向完全一致。
4. **麦克风与收听状态明确标识**：联机房真人座位展示 `麦开 / 麦关` 及 `发言中 / 收听中 / 已静音` 标签并配切换 Toast 提示。
5. **实时 FPS 与连接延迟遥测**：局内、房间与结算右上角展示实时平滑 FPS；局域网/在线服务器基于 ENet 传输层展示真实连接状态与毫秒延迟。
6. **端到端性能优化**：角色立绘压缩至 `384×512`（减少 87.1% 体积/显存）、按需懒加载牌面 UV 与预导入音频、非对局停用后台 3D 视口、池化网格与样式对象。
7. **官方门户前后端上线**：内置新中式官网前端（`remake/web/`）及 `/v1/status`、`/v1/releases`、`/v1/downloads/` 后端接口，支持在线看房、网页建房、APK 校验下载与接口联调。
