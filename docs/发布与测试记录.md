# 发布与测试记录

## v2.4.1（2026-11-27 · Build 8）

### 版本变更摘要

1. **麦克风开启全面修复（客户端 + 服务端 GME + ENet PCM 自动回退）**：
   - 修复首次安装时语音控制器获取的在线目录地址为空导致无法申请鉴权的问题（改用 `_online_url()`），真实展示开启/权限/异常状态 Toast，名片新增 `开启中` 金色过渡态。
   - 生产容器注入腾讯 GME 签权环境变量（`https://mj.dongxiu.fun/v1/status` 返回 `voice_configured: true`），并在 GME 不可用环境下自动无感回退至内置 ENet PCM 语音中继。
2. **本家手牌放大与防误触**：手牌缩放提升至 `2.06×`、倾角 `68°`、选牌抬高 `0.56`，增大点击/长按容差并采用水平加权拾取，降低相邻手牌误触。
3. **开局高清大骰子**：骰子视觉放大 `2.25×`（保持物理边长与协议 4 兼容），着色器放大红白高对比点数与 1/4 点朱砂红凹点。
4. **胡牌结算展示具体番型**：牌型项在胡牌张后直接显示具体牌型与分值（如 `大对子+14`、`清一色+24`、`小七对+24`、`龙七对+44`），冲锋鸡继续保持横置金边对齐。
5. **100 个纯麻将昵称库与人机去重**：彻底移除人机牌名昵称，新增 100 个无重复麻将主题昵称（`MahjongNames.gd`），资料页新增「挑昵称」5 列滚动选单，人机座位不重复抽取且自动避开玩家重名。
6. **结算前「翻鸡时刻」前置展示**：胡牌后先在无遮挡亮牌桌面上高亮翻出鸡牌与 3 张关联鸡牌（含 `金鸡×2` 提示），停留 2.6 秒（可随时点「查看结算」跳过）再展示结算面板。

### 渲染显存与工程专项优化前后实测对比（Godot 4.7.2 · GL Compatibility · 1600×900）

| 场景 / 指标 | 优化前基线 | 优化后实测 | 变化 |
| --- | ---: | ---: | --- |
| **大厅待机显存（VRAM / 纹理）** | `41.50 MB` / `34.94 MB` | **`37.50 MB`** / **`30.94 MB`** | **-9.6%**（-4.00 MB） |
| **单机精致档显存（VRAM / 纹理）** | `310.48 MB` / `303.98 MB` | **`49.37 MB`** / **`42.87 MB`** | **-84.1%**（直降 **261.11 MB**） |
| **单机流畅档显存（VRAM / 纹理）** | `296.42 MB` / `289.92 MB` | **`35.31 MB`** / **`28.81 MB`** | **-88.1%**（纹理降至 1/10） |
| **单机牌桌 Draw Calls** | `169` | `169` | 远低于 300 门槛，无需 MultiMesh |
| **AI 后台决策耗时（低 / 中 / 高中位数）** | `11.19 / 11.21 / 11.25 ms` | `11.37 / 11.23 / 11.25 ms` | 后台线程池异步执行，零主线程卡顿 |
| **`Main.gd` 代码规模** | `3,294` 行 | **`2,546` 行**（-748 行） | 抽离 `MainLobbyBuilder.gd`、`LeaveConfirmOverlay.gd` |

> **关键优化项说明**：
> 1. 定位并移除 GL Compatibility 下单节点永久占用 257 MB 显存的 `ReflectionProbe`（保留零显存消耗的 `REFLECTION_SOURCE_BG` 温润反光）。
> 2. 方向光阴影距离由 `85.0` 收紧至 `42.0`，移动端阴影图设为 `1024`，牌墙与弃牌关闭阴影投射，仅手牌/副露/鸡牌/骰子保留立体投影。
> 3. 新增流畅档专用无采样法线着色器 `TileResinSmooth.gdshader`；`mahJong.png` 开启 mipmap 消除斜视闪烁，`mahJong_NORM.png` 开启 VRAM 压缩 + normal_map + mipmap。
> 4. 新增设置项「省电帧率 (30 FPS)」、移动端首局 3 秒低帧（<34 FPS）自动降流畅档、虚拟键盘高度轮询改为输入框聚焦触发。
> 5. 新增 `Android Release (arm64-v8a)` 纯 64 位导出预设、`remake/version.json` 单一版本源，以及 `compose.yaml` / `compose.prod.yaml` 容器内存/CPU/PID 硬限额。

- **RTX 5060 GPU 渲染验收**：逐张核验 2.06× 手牌、2.25× 骰子、100 昵称选单、翻鸡时刻前置、`大对子+14` 结算画面，以及移除反射探针后的精致/流畅双档实景与设置省电开关。
- **逍遥模拟器（Android 9 · 1600×1000）实机联机验收**：
  - 冷启动耗时：**1.88 秒**。
  - 首次建档「挑昵称」选入 `天选雀神`，单机开局大骰子与 2.06× 大手牌清晰无误触，人机名称为 `翻鸡福星`、`夜战麻将`、`牌神附体` 等纯麻将昵称，结算页冲锋鸡横置对齐。
