# 安顺麻将·捉鸡 游戏规则总纲

本文是当前唯一的游戏规则、V2 桌面布局和实现验收文档。

游戏规则统一维护在本文。README、历史记录、GitHub 旧规则文档和外部核对报告仅作背景资料，不另设规则来源。代码与测试若和本文不一致，应按本文修正；已有测试通过不代表新增规则已经实现。

2026-11-05 算分核对结论已合并到第六至十二章；实现差异与验收状态见第14.3节。

当前已确认的规则：

```text
单机第一局：南方玩家1坐庄
牌墙上层：玩家自己视角向左8，同时朝该玩家手牌方向8
南墙牌背：不旋转180，白色牌体边朝桌内
```

# 一、基础规则

## 1.1 牌

```text
108 张
万、条、筒三门
每门 1~9，每张 4 份
无花牌、风牌、箭牌
```

牌值字符串：

```text
wan1..wan9
tiao1..tiao9
tong1..tong9
```

鸡牌：

```text
幺鸡 = tiao1
八筒 = tong8
```

## 1.2 座位

固定罗盘座位：

```text
0 = 东
1 = 南
2 = 西
3 = 北
```

联机新玩家依次分配第一个空座：南 → 东 → 北 → 西。重连恢复原座位。

玩家出牌顺序为逆时针：

```text
东 → 北 → 西 → 南 → 东
```

牌墙物理顺序为顺时针：

```text
北 → 东 → 南 → 西 → 北
```

两者不是同一套顺序：前者是玩家行牌顺序，后者是牌墙取牌顺序。

## 1.3 分数

```text
每家初始 200 分
四家合计 800 分
允许负分
单机、联机都保留累计分数
```

## 1.4 基本行牌

```text
只能碰、杠、胡
不能吃
```

## 1.5 单机庄家

```text
单机第一局：本地玩家坐庄，即南位1
后续按连庄/换庄规则
联机第一局由房间规则决定
```

单机首局不使用东位0，固定由本地南位玩家先坐庄。

# 二、牌墙模型

## 2.1 两层 54 蹲

```text
54 蹲
一蹲 = 上层 poker[0] + 下层 poker[1]
北/南各 14 蹲
东/西各 13 蹲
合计 108 张
```

段长度：

```text
北墙：28 张（14 蹲）
东墙：26 张（13 蹲）
南墙：28 张（14 蹲）
西墙：26 张（13 蹲）
```

## 2.2 牌墙环 ring

`ring` 按物理取牌方向排列：

```text
ring[0..27]    北墙，左 → 右
ring[28..53]   东墙，上 → 下
ring[54..81]   南墙，右 → 左
ring[82..107]  西墙，下 → 上
```

四段：

```gdscript
SEG = {
    0: {"start": 0,  "len": 28, "seat": 3},  # 北
    1: {"start": 28, "len": 26, "seat": 0},  # 东
    2: {"start": 54, "len": 28, "seat": 1},  # 南
    3: {"start": 82, "len": 26, "seat": 2},  # 西
}
```

## 2.3 建立牌墙

入口：

```text
RoundState.start_round()
→ WallBuilder
```

流程：

```text
生成 108 张
Fisher-Yates 洗牌
按 28 / 26 / 28 / 26 切成四面墙
按物理取牌方向生成 ring
WallRing 保存 _ring、_drawn、_head、_tail、remaining
```

## 2.4 定庄与破墙

定庄：

```gdscript
dealer_seat = posmod(next_dealer_seat, 4)
```

单机第一局：

```text
next_dealer_seat = 本地玩家（南1）
```

联机第一局由抢庄决定：

```text
有人抢庄：只在抢庄玩家里随机
无人抢庄：四个座位随机
```

## 2.5 骰子破墙

红骰决定破墙侧，白骰不参与破墙：

```text
红骰 1/3/5 → 对家墙
红骰 4     → 上家墙
红骰 2/6   → 下家墙
```

逆时针顺序：

```gdscript
offset = 2 if die in [1, 3, 5] else (1 if die == 4 else 3)
target = posmod(dealer_seat + offset, 4)
```

破墙点：

```gdscript
break_index = segment.start + die * 2
```

因为一蹲是两张，`die * 2` 表示跳过 `die` 蹲。

设置牌头：

```gdscript
wall.set_head(break_index)
```

## 2.6 牌头与牌尾

牌头用于普通摸牌：

```text
从当前唯一未摸完墙段开始
每列先上层、再下层
北/东正向递增
南/西向物理小号方向推进
```

牌尾用于杠后补牌：

```text
最后一列上层
最后一列下层
前一列上层
前一列下层
...
```

牌头、牌尾共用 `_drawn`，不会重复摸同一张。

## 2.7 剩余量

```text
remaining = 108 - 已摸走张数
```

包括发牌、普通摸牌、杠后补牌。

翻鸡牌只是 `peek_head()`，**不摸走**，不扣剩余。

# 三、开局发牌

## 3.1 总量

```text
每家 3 轮 × 4 张 = 12 张
四家共 48 张
再按顺序每家 1 张，共 4 张
总计 52 张
每家 13 张
```

庄家第 14 张不在开局发牌阶段发。

## 3.2 发牌顺序

以庄家为起点，逆时针：

```text
庄家 → 下家 → 对家 → 上家
```

南庄示例：

```text
南 → 东 → 北 → 西
```

每轮每家拿两蹲（4 张）：

```text
第 c 列上层
第 c 列下层
第 c+1 列上层
第 c+1 列下层
```

两组两蹲可以跨墙，墙段是连续环，不能丢弃剩余一蹲。

## 3.3 发完后

```text
四家各 13 张
牌墙剩余 56 张
进入13张排序
排序完成后庄家摸第14张
庄家变14张，先出牌
```

庄家摸完后牌墙剩余 55 张。

# 四、普通摸牌与杠后补牌

## 4.1 普通摸牌

```gdscript
wall.draw_head()
```

每回合摸 1 张。

顺序：

```text
北墙：左 → 右
东墙：上 → 下
南墙：右 → 左
西墙：下 → 上
```

同一列永远先上层、后下层。

## 4.2 杠后补牌

```gdscript
wall.draw_tail()
```

从最后一列开始，按上层、下层、前一列上层、前一列下层。

杠后补牌不改变翻鸡位置；翻鸡仍看牌头下一张。

## 4.3 牌墙耗尽

```text
draw_head() 返回 ""
→ 荒牌/流局流程由 RoundState 处理
```

# 五、行牌与响应

## 5.1 当前回合

当前玩家摸 1 张后可以：

```text
自摸
暗杠
加杠
否则打出1张
```

## 5.2 响应优先级

```text
胡 > 杠 > 碰 > 下家摸牌
```

顺序：

```text
先开放胡牌窗口
所有可胡玩家处理完
再开放杠
杠家全部过牌
再开放碰
```

## 5.3 多人胡

同一张弃牌允许多人同胡。

## 5.4 过胡/过碰

```text
未报听者过胡：本人下一次摸牌前不能再胡别人，下一次摸牌解除
报听者过胡：本局之后只能自摸，不能胡任何玩家的弃牌，也不能抢杠胡；摸牌不解除，下局清除
过碰：本人下一次摸牌前不能再碰同一张牌
```

报听成功时统计锁定手牌的全部可胡牌张。其他玩家打出其中任何一张、或加杠时该张可被抢杠胡，报听者在可胡窗口选择「过」，即触发整局过胡锁，不只限制本次放过的牌。例如同时听三万和六万，过掉别人打出的三万后，之后三万、六万都不能再胡别人，自己摸到仍可自摸。单一听张同样适用；没有胡牌资格时过牌、放弃自己的自摸，均不触发这条限制。报听状态、叫牌与计分判定保持，联机重连或切换AI代打不解除限制；可胡牌张列表只发给本人，不向其他玩家泄露。

## 5.5 报听后

```text
不能换牌
自动摸打
只打刚摸到的牌
摸到可自摸或别人点炮可胡时停下等待选择；报听过胡后只在可自摸时停下，不再提供弃牌胡或抢杠胡
```

# 六、碰与杠

## 6.1 碰

```text
手里至少2张相同牌
移除2张
与来源弃牌组成碰
碰牌者继续出牌
```

碰后不能立即打出刚碰进来的同一牌值。

## 6.2 明杠

```text
手里3张，别人打出第4张
从牌尾补1张
基础杠分4分
只在杠主与放杠者之间结算，方向按第6.6、11.4节
```

## 6.3 暗杠

```text
开局已有4张，第一次弃牌前可以暗杠
本回合摸到第4张，本次弃牌前可以暗杠
选择弃牌后，这张牌本局不能再暗杠
从牌尾补1张
基础杠分4分，付款资格按第6.6节；流局例外见第十二章
自己的视图立即显示暗杠牌面
其他玩家先看到反扣
完成后续两次出牌后公开翻开
暗杠获得胡牌通行资格
```

## 6.4 加杠

```text
已经碰过
之后摸到第4张才能加杠
宣告后先进入抢杠胡窗口
加杠成功从牌尾补1张
基础杠分4分，付款资格按第6.6节；流局例外见第十二章
可以被抢杠胡
```

## 6.5 杠后通行

```text
明杠后的弃牌：不开放普通小牌杠后通行
暗杠后的第一张弃牌：开放
加杠后的第一张弃牌：开放
```

## 6.6 杠分付款资格

胡牌局的一般规则：

```text
叫牌者暗杠/加杠：其他三家各付4，不要求付款者叫牌
明杠：只在杠主与放杠者之间结算基础4，完整方向见第11.4节
未叫牌杠主：不能收正分
未叫牌明杠：只向已叫牌的放杠者反付4
未叫牌暗杠/加杠：反向付给每位叫牌者
未叫牌玩家之间永远不互付
```

流局时优先按第十二章处理：部分叫牌流局，叫牌者之间不结杠分；四家全叫流局，本局所有收付为0。烧鸡者的收入和付款按第9.3节处理。

## 6.7 杠中鸡与基础杠分分开计算

胡牌局中，叫牌杠主的杠内鸡分如下：

| 杠牌种类 | 四张合计鸡分 |
| --- | ---: |
| 普通非鸡牌命中翻鸡范围 | 4 |
| 幺鸡或八筒，未翻成金鸡 | 8 |
| 幺鸡或八筒，翻成金鸡 | 16 |

上述鸡分参与全场两两鸡分比较，明杠也一样；杠基础4另按付款资格结算。杠内鸡分只计一次，不再向放杠者额外重复收取。

未叫杠主的普通翻鸡杠不产生翻鸡债务，也不记普通翻鸡负分；幺鸡/八筒杠中的鸡仍按8或16向每位叫牌者补付。基础杠分另算。流局不翻鸡，杠中幺鸡/八筒按8计算，不产生本局金鸡16或普通翻鸡4。

# 七、胡牌通行条件

普通弃牌胡牌，至少满足一项：

```text
胡牌玩家已报听
弃牌者已报听
这张牌是暗杠/加杠后打出的第一张
牌型为大对子或更高
小七对、龙七对
清一色或清一色特殊牌型
胡牌玩家自己有暗杠
胡牌玩家自己有加杠
当前是抢杠胡阶段
```

通行证：

```text
玩家自己有暗杠或加杠
明杠不算
```

普通小牌没有上述条件时只能自摸。

# 八、报听与胡牌费用

## 8.1 报听条件

```text
第一次摸牌后的出牌机会
打出一张即可听牌时可以报听
此前只允许暗杠
不能有碰、明杠、加杠
```

## 8.2 报听行为

```text
不能换牌
自动摸打
只打刚摸到的牌
可自摸/点炮时停下等待选择
```

## 8.3 报听费用

报听24包含基础4。以下金额均为单倍，鸡分、杠分和其他独立费用另算。

```text
没有计分牌型时：报听胡牌24，不另加普通自摸4
有计分牌型T时：T + 24 - 4 = T + 20
赢家已报听时不计干扣或大干扣
```

付款人：

```text
自摸：其他三家各付适用于自己的胡牌费用
胡别人弃牌：只由放炮者付赢家的胡牌费用
```

赢家和放炮者都报听时，双方的报听项目合并，仍只保留一个基础4：

```text
没有计分牌型：24 + 24 - 4 = 44
只有大对子14：14 + 24 + 24 - 4 - 4 = 54
还有其他可叠加项目时，按第8.5节统一去重
```

此处不另收杀报；自摸赢家已报听时，也不因付款者报听再加一份杀报。各类特殊费用是否适用，另按第8.6节判断。

## 8.4 杀报

赢家未报听时：

```text
报听者放炮：该报听者向赢家付杀报24
其他玩家自摸：每位报听付款者分别向赢家付杀报24
未报听的其他付款者不付杀报
```

杀报可与牌型叠加，两项内含的基础4只算一次。若赢家是干扣或大干扣自摸，已报听的付款者只付杀报24，其他未报听的付款者照付干扣14或大干扣24。

赢家也报听时，按第8.3节结算报听胡牌，不再额外收杀报。

## 8.5 叠加项目与基础4去重

先选定最高的一项计分牌型。牌型可以与报听或杀报叠加；干扣和大干扣只在无计分牌型、赢家未报听的自摸中二选一，并且只向未报听的付款者收取。

对每名付款人，分别合并适用于他的项目。若其中有N个包含基础4的项目：

```text
合并金额 = 各项目分值之和 - 4 × (N - 1)
```

普通自摸4不在这些含基础4的项目之外重复收取。鸡分、杠基础费、通行证4、抢杠12、杠后放炮17/21、杠开5、海底5属于各自独立款项，不因数值含4而按本公式扣除。

以下只算胡牌费用，鸡分、杠分和其他独立款项另算：

| 同时成立的项目 | 合并计算 | 金额 |
| --- | --- | ---: |
| 干扣自摸，付款者已报听 | 杀报24 | 24 |
| 干扣自摸，付款者未报听 | 干扣14 | 14 |
| 大干扣自摸，付款者未报听 | 大干扣24 | 24 |
| 大对子 + 杀报 | 14 + 24 - 4 | 34 |
| 零鸡无杠，赢家报听，无计分牌型 | 报听24 | 24 |
| 零鸡无杠，大对子自摸 | 大对子14 | 14 |
| 零鸡无杠，清一色自摸且赢家报听 | 24 + 24 - 4 | 44 |
| 大对子 + 赢家报听 + 放炮者报听 | 14 + 24 + 24 - 8 | 54 |

干扣例子均假设至少另一位叫牌者有鸡或有杠，因而不升级为大干扣。胡牌资格仍须满足第七章，不能用干扣或大干扣绕过胡牌通行条件。

## 8.6 独立胡牌费用

| 项目 | 条件 | 付款人 |
| --- | --- | --- |
| 普通点炮基础0 | 普通弃牌被胡 | 放炮者；牌型、报听、杀报等另算 |
| 杠后放炮17/21 | 暗杠/加杠后第一张弃牌被胡；放炮者叫牌为17，未叫为21 | 放炮者 |
| 通行证4 | 赢家自己有暗杠/加杠，以未报听、无计分牌型的普通小牌胡别人弃牌；抢杠不加此项 | 放炮者 |
| 抢杠12 | 抢加杠胡 | 被抢杠者 |
| 杠开5 | 杠后补牌自摸 | 其他三家各付5 |
| 海底5 | 牌墙最后四张中的任意一张自摸 | 其他三家各付5 |

符合条件的独立费用另付。杠后放炮与赢家通行证可叠加为17+4=21或21+4=25；杠开与海底可以同时成立。牌型、报听、杀报等再按各自付款人和基础4去重规则计算，一炮多响按每位赢家分别结算。

# 九、鸡牌、翻鸡、烧鸡

## 9.1 鸡牌

```text
一条（幺鸡）
八筒
```

分值：

```text
全场每种第一张打出：冲锋鸡4
之后打出：普通鸡2
手中保留：每张2
碰中、杠中：每张2
冲锋鸡被碰/杠后按普通鸡算，不再保留冲锋标记
```

## 9.2 翻鸡

只有胡牌局翻鸡，流局不翻。

```text
翻开牌头下一张
只 peek，不摸走
范围：本张、上一张、下一张
1 的范围：9、1、2
9 的范围：8、9、1
```

计分：

```text
普通翻鸡牌每张1
范围里的幺鸡/八筒为金鸡
普通金鸡4
冲锋金鸡8
其他两张仍按翻鸡1
```

叫牌者的手牌、碰中、杠中普通牌命中翻鸡时计分；未叫牌者的普通翻鸡不计收入，也不形成债务，普通翻鸡杠同样如此。未叫牌者手中的幺鸡/八筒不计正分；其出牌鸡、碰中鸡、杠中鸡仍按债务向叫牌者补付，翻成金鸡时使用对应的金鸡值。

## 9.3 烧鸡

被胡玩家烧鸡：

```text
抢加杠胡
暗杠后打出的牌被胡
加杠后打出的牌被胡
```

烧鸡只把自己的鸡分归0：

```text

自己的杠收入不计
仍必须赔付赢家的鸡分、杠基础分、放炮分
抢杠/杠后放炮等非鸡分照付
```

## 10.1 干扣与大干扣的成立条件

干扣14只适用于没有计分牌型且未报听的合法自摸。本人还须同时满足：


| 其他玩家状态 | 对大干扣的要求 |
| --- | --- |
| 未叫牌 | 在大干扣资格判断中按鸡分0处理，其手中鸡、鸡分债务或杠不阻止大干扣 |
| 已叫牌（含其他赢家） | 鸡分为0：无手中、碰中、保留出牌鸡，也没有命中翻鸡；并且没有任何杠 |

# 十一、计分与付款

## 11.1 个人分

个人分用于展示自己产生的计分项目，不等于本局累计分数的净变化，也不能把四人的全部个人分直接相减代替付款流水。

叫牌者：

```text
手里鸡 + 保留的出牌鸡 + 碰里鸡 + 杠里鸡 + 翻鸡
+ 牌型分 + 杠基础分
+ 报听分 + 胡牌基础分
```

其中胡牌费用先按第8.5节合并、去重；杠基础分按第6.6节的实际付款资格统计。未胡的叫牌者不因潜在牌型收胡牌费，流局查叫补付另按第12.3节。

未叫牌者：

```text
-（打出的鸡 + 碰里的鸡 + 杠基础分 + 杠里鸡）
```

未叫者的手中鸡和普通翻鸡不列入此负分；普通翻鸡杠也不额外扣翻鸡4。未叫者的明杠基础4仅作为与已叫牌放杠者有关的债务，暗杠/加杠基础4则向每位叫牌者补付。明细与实际付款必须使用同一债务口径。

鸡基础值：

```text
普通鸡：2/张
金鸡：4/张
冲锋鸡：4（翻中8）
杠中鸡：8（翻中16）
翻鸡普通牌：1/张
```

胡牌基础：

```text
自摸4
干扣14
大干扣24
点炮0
杠后放炮17（放炮者已叫）/21（没叫）
抢杠12
通行证4
杀报24
杠开5
海底5
```

## 11.2 两两相对分

先按两人的叫牌状态比较鸡分，再加入各自应付的独立款项，最后只保留两人之间的一笔净收付：

| 两人状态 | 鸡分结算 |
| --- | --- |
| 双方叫牌 | 鸡分少的一方向多的一方支付差额，含杠中鸡与普通翻鸡杠的鸡分 |
| 只有一方叫牌 | 未叫者支付叫牌方鸡分，并补付自己应付的出牌鸡、碰中鸡、杠中鸡债务 |
| 双方未叫 | 永远不互付 |

杠基础费、实际胡牌者的牌型/干扣/大干扣、报听、杀报及特殊胡牌费，按各自付款人加入这两人的流水，不能一律作为全场分差处理。付款人适用的胡牌项目先按第8.5节去重。流局的付款范围以第十二章为准。

最后将A应付B与B应付A的款项相抵，每对只形成一个净额；四家净变化之和必须为0，累计总分保持800。

## 11.3 特殊款项

```text
牌型分：点炮只由放炮者付给赢家
报听24/20：点炮只由放炮者付
抢杠12：只由被抢杠者付
杠后放炮17/21：只由放炮者付
通行证4：只由放炮者付
杀报24：赢家未报听时，由报听放炮者或被自摸的每位报听者各自支付；基础4按第8.5节去重
明杠基础4：只在杠主与放杠者之间结算，方向按第11.4节
杠中鸡（含明杠）：参与全场两两鸡分比较，基础4另算
```

暗杠、加杠基础4：

```text
胡牌局叫牌杠主：其余三家各付一份
未叫杠主：反向付给每位叫牌者
流局：叫牌者之间不互付；四家全叫时本局全部0
```

## 11.4 明杠最后算

明杠基础4只比较杠主与放杠者，不混入对其他两家的基础杠费。杠中鸡已经按第6.7节参加鸡分结算，不在此重复收取。

| 杠主状态 | 放杠者状态 | 胡牌局基础杠费 | 部分叫牌流局基础杠费 |
| --- | --- | --- | --- |
| 叫牌 | 叫牌 | 放杠者付杠主4 | 0 |
| 叫牌 | 未叫 | 放杠者付杠主4 | 放杠者付杠主4 |
| 未叫 | 叫牌 | 杠主反付放杠者4 | 杠主反付放杠者4 |
| 未叫 | 未叫 | 0 | 0 |

四家全叫流局，本局所有收付为0，不再按胡牌局矩阵收明杠4。烧鸡者不收收入，仍按第9.3节承担对其他玩家的应付款。

## 11.5 倍率

倍率在结算最后统一乘一次，覆盖所有收付：

```text
鸡分（含金鸡、冲锋鸡、杠中鸡、翻鸡）
自摸/干扣/大干扣
牌型分
杠基础分
报听费
杀报费
抢杠费
杠后放炮费
通行证/杠开/海底
```

红白骰同点：

```text
本局所有收付 ×2
```

与流局后带入的倍率共用，最高×2，不叠加×4。所有流局均使下一局为×2；只有完成胡牌局后，下一局恢复×1。

## 11.6 两人付款核对例

以下均为单倍，A、B未报听；没有列出的计分项不计入例子。

### 例1：未叫者的普通翻鸡杠不产生翻鸡债务

```text
A自摸：123万｜234条｜456筒｜111条｜99筒
B暗杠：5555万
B手牌：1、3、8、9万；2、5、8条；1、4、7筒（未叫）
翻牌：六万，范围五、六、七万
```

A普通自摸4，三张幺鸡6；B未叫，向A反付暗杠基础4。B杠中的普通翻鸡4不形成债务：B付A = 4 + 6 + 4 = **14**。B这一组杠的负分明细只记基础−4，不记为−8。

### 例2：部分叫牌流局，叫牌者之间不结杠分

```text
A暗杠：5555万
A手牌：123万｜234条｜123筒｜9万（听九万）
B手牌：678万｜567条｜456筒｜999筒｜9条（听九条）
另外两家未叫，牌墙摸完流局，不翻鸡
```

A、B均叫牌，两人之间不结鸡分差或杠基础分，净付款 **0**。A的暗杠换成加杠，结论相同；另外两名未叫者的补付款分别计算，不改变A、B这一对的0。

### 例3：四家全叫流局，明杠也不付4

沿用例2中A、B的手牌，A的五万杠改为明杠，来源是B打出的第四张五万；另外两家也叫牌。四家全叫流局，本局全部不计分，因此B付A **0**，不再另付明杠基础4。

# 十二、流局、包牌、下一局庄家

## 12.1 流局

```text
牌墙摸完无人胡牌
不翻鸡
不产生本局金鸡或普通翻鸡分
所有流局均使下一局所有收付×2，连续流局仍封顶×2
```

## 12.2 四家都叫

```text
本局所有分项和收付均为0，包含明杠、暗杠、加杠基础分与杠中鸡
下局所有收付×2
连续流局倍率仍封顶×2
当前庄家连庄
```

## 12.3 包牌

有人未叫牌，未叫牌者向每位叫牌者补付：

```text
双方已打出的幺鸡/八筒
双方碰中的幺鸡/八筒
应付的杠基础分、杠中鸡，按叫牌资格分别结算
叫牌者能听成的最高牌型分；没有牌型则付4
```

牌型补付替代荒牌基础4，不额外叠加。例如听清一色时收24，不收28；听多张时按各张成胡后的实际牌型取最高值，龙七对仍须由该假定胡牌张凑成第四张。此处是流局查叫，不另计报听、杀报、干扣或大干扣胡牌费用。

流局不翻鸡，普通出牌鸡按2、冲锋鸡按4、碰中鸡每组6、杠中鸡每组8计算；没有本局金鸡或普通翻鸡。全场每种首张鸡是否仍归本人，按碰杠后的实际归属判定。

```text
叫牌者之间不补鸡分差，也不结明杠、暗杠、加杠基础分
手中鸡不加入本次补分
未叫牌者不因手中鸡产生正分
未叫牌者之间不互付
四家均未叫时没有收款人，本局所有收付为0，下局仍×2
```

对一名叫牌者与一名未叫者，暗杠/加杠基础4由未叫者付给叫牌者：未叫者自己的杠基础4反向付，叫牌者自己的杠基础4正常收。明杠只比较杠主与放杠者，方向见第11.4节。全部查叫补付汇总后，再应用本局倍率一次。

## 12.4 下一局庄家

```text
有人胡：胡牌者中本局净得分最高者当庄，并列随机
流局且有人未叫：未叫牌者中失分最多者当庄，并列随机
四家都叫流局：当前庄家连庄
```

```text
牌墙牌面倍率：1.35（64.8×86.4），与其他玩家手牌和碰杠牌面同尺寸
```

## 13.3 手牌与摸牌

```text
自己：115.2×153.6
其他三家：64.8×86.4
手牌间距：4
摸牌区与手牌边缘：20
```

自己永远在屏幕下方，其他三家按相对座位旋转。

手牌槽位方向：

```text
南：左→右
北：右→左
东：下→上
西：上→下
```

摸牌位置：

```text
自己：手牌右端
北：手牌左端
东：手牌上端
西：手牌下端
```

手牌平时自身中心对齐；碰、明杠、暗杠、加杠落位后，剩余手牌立即进行快速居中，不再等到本人下一次出牌。居中时长为牌面速度的40%，最多0.12秒；牌面速度为0时立即完成。飞牌与居中结束前禁止手牌操作，完成后再开放输入；单机与联机一致。

牌局中「排序」按钮始终保留，摸牌时不消失；位置跟随实际摸牌位置，碰杠后手牌变短时不再停在13张牌的旧位置，「恢复」位于其左侧。排序提示与AI教学各留独立的两行区域，不与两个按钮重叠。飞牌、碰杠动画或重连等待期间暂时禁用。支持未碰杠的13张手牌，以及碰杠后剩余的10、7、4、1张；摸牌后也可点击排序，将摸牌并入手牌。排序只调整本人看到的排列，不修改权威手牌数组、牌张身份或其他玩家视图。未轮到自己时也可排序、恢复和切换排法，但不能因此启用出牌或解除报听锁牌。

- 未摸牌时：循环展示当前已叫牌的全部有效拆法；未叫牌时展示最接近叫牌的拆法。成组的刻子、顺子和对子在左，散张在右。已固定的碰杠参与牌型判断，位置不变。
- 摸牌并入后：将14、11、8、5、2张实际手牌一起整理，轮看合法弃牌后最接近叫牌的方案，提示「打哪张后听哪些牌」。碰后不能立即打出的同值牌不列为建议弃牌；报听者只建议打刚摸到的牌。
- 此时若可自摸，点击排序视为放弃本次自摸，通过权威操作记录并同步。点击恢复、联机重连、切换AI代打均不能恢复本次自摸机会，下一次摸牌（包括补牌）解除。此行为不触发第5.4节的弃牌胡／抢杠胡过胡锁；已有的报听整局过胡锁仍按原规则保持。报听玩家仍锁手牌，放弃自摸后继续按原规则自动摸打。
- 未报听且没有待处理的摸牌时，可继续轮看「打出一张、换入一张后能叫大牌」的全部有效方案，不搜索换两张及以上。换牌是提示而非真实动作，不插入假想牌，不允许与本人已有碰杠合计超过四张。报听后仅查看现有拆法，不提供换牌方案；报听过胡时明确显示「本局只能自摸」。
- 每张听张的牌型和单倍牌型分以实际胡牌后的最高牌型判定；视觉上选择顺子拆法不会降低同一副牌实际成立的七对等牌型。不把报听、干扣、鸡分或杠分当作已确定的牌型分。宽张指可胡的不同牌值数，不表示牌墙剩余张数；平胡仍须满足第七章的胡牌通行条件。
- 默认宽张优先、牌型次之，沿用已有个人设置，本次不调整设置页面。相同方案不重复，连续点击可以循环遍历。换牌方案异步计算，恢复、换手牌、报听或下一局后不应用旧的计算结果；旧任务结束后，当前仍处于排序模式的手牌自动补算，不要求额外点一次。摸牌并入后再打出，即使剩余13张牌与此前完全相同，也要恢复完整的换牌方案，不能仅留下基础排法。点击「恢复」回到按牌值排序；已并入的摸牌不再次分离，也不撤销已经放弃的自摸。摸切保留排列，真实换牌后优先保留仍成立的牌组。已并入的摸牌无论自己被打出，还是保留而打出旧牌，都必须结束本次摸牌的临时显示，不能在右侧重新出现多余的一张牌。

AI教学用短句说明首选操作，其他推荐另起一行，例如「先打9万」「也可以考虑1万、5万」，不在提示里重复AI强度或把未见牌数说成牌墙余量。排序用「打9万后，听……」说明当前排法；需要以后摸到特定牌的方案写成「若摸到5万，再打1万，听……」，不把假设当作当前已经叫牌。两类提示各自最多两行，分开显示；单机、联机和AI代打教学使用相同措辞，不改变推荐决策、排序优先级或胡牌规则。

## 13.5 弃牌

普通弃牌统一为64.8×86.4。自己与对家各两行、每行12张，上家与下家按各自视角每行6张、共四行，四家容量均为24张。先铺满靠近桌心的一行，再向出牌者方向展开下一行。每行第一张居中；后续牌先飞到已有牌列的玩家视角右侧，再将该行整体居中。飞行和居中共用一次牌面动画时长，不额外增加等待。四家的完整槽位范围互不相交，并避开完整牌墙。两侧牌墙向上预留本家第14张摸牌的空间，包含牌墙阴影也不得覆盖手牌或摸牌；牌张大小、墙环顺序与摸取规则不变。

容量预测：108张牌发完每家13张后剩56张，庄家首次摸牌后剩55张。忽略同牌张数、允许每家最多四次任意碰牌，用剩余摸牌数、四家碰组数、当前出牌座位枚举全部跳转；被碰走的牌不计入原出牌者的留桌弃牌。这个放宽模型涵盖上家连续碰牌，并给出单家留桌弃牌至多20张的上界；杠补牌额外消耗牌墙，不提高该上界。普通牌河24槽之外，出牌鸡另占本家碰杠区的预留位置。

普通弃牌按本家左→右、对家右→左、上家上→下、下家下→上的方向依次放置。最近一张的高亮只画在牌面以内。被碰杠取走的牌退出原牌河，进入碰杠组；牌河容量按当前留在桌上的弃牌计算。

## 13.6 出牌鸡

打出的幺鸡、八筒放在出牌者自己的碰杠区，独立于普通牌河，使用正常牌面颜色。南北碰杠区牌面为64.8×86.4，东西碰杠区统一按85%缩放为55.08×73.44；同一座位的单张鸡和碰杠牌保持一致，冲锋鸡仅旋转90度。单张鸡优先从居中庄／听标记左侧向外排，最多六张；右侧优先容纳碰杠，后来的单张鸡排在碰杠外侧。优先使用手牌上方的一行，整组放不下时才利用已空出的手牌两端；落位与快速居中期间按真实手牌及摸牌位置避让，动画结束后按居中位置检查。鸡牌被碰杠时从原位置飞出，其余牌移动让位。结算仅隐藏普通弃牌区；碰杠区全部牌始终保留，包括碰、明杠、暗杠、加杠，以及打出的幺鸡、八筒和冲锋鸡。自摸、胡牌、部分叫牌流局、四家全叫流局均如此，单机与联机保持一致；结算动画、完成后的刷新和重连均不得隐藏这些牌。保留实际剩余牌墙与结算计分。

## 13.7 碰杠区与飞行

鸡牌和普通牌的碰杠共用各自座位的碰杠区，使用13.6的统一尺寸；每家最多四组，均整组落位。

中间保留庄家与报听标记的位置。优先用满手牌上方行，在空间足够时左右各容纳两组暗杠长度；受鸡牌或手牌原位置影响时，整组移入可用的手牌两端，不能拆散牌组或盖住其他牌。静态显示、动画落点、联机快照与重连共用同一布局计算。

碰杠较多时优先利用该玩家减少手牌后空出的同行位置，不借用邻家手牌旁的边角。南北两家的横向范围限制在东西牌墙之间，东西两家的纵向范围限制在自身开局手牌长度内；仍须避让实际保留的手牌、独立摸牌、庄／听标记、名字分数、操作按钮、牌墙和普通弃牌。两条固定落位线都放不下时，在本家空出的手牌带内调整整组位置；必要时检查本家牌墙内侧的空位，不能跨到其他玩家区域。对家来源明杠按三张竖牌加前方横牌的完整两排外形（含阴影）检查空间，不能只计算三张竖牌的占位。

```text
上家放出的明杠来源牌横放在杠主视角的左端，下家放出的横放在右端
```

## 13.8 HUD、按钮、结算
