# 安顺麻将·捉鸡 游戏规则总纲

本文是当前唯一的游戏规则、V2 桌面布局和实现验收文档。

游戏规则统一维护在本文。README、历史记录、GitHub 旧规则文档和外部核对报告仅作背景资料，不另设规则来源。代码与测试若和本文不一致，应按本文修正；已有测试通过不代表新增规则已经实现。

2026-11-05 算分核对结论已合并到第六至十二章；实现差异与验收状态见第14.3节。

当前已确认的规则：

```text
单机第一局：南方玩家1坐庄
牌墙上层：玩家自己视角向左8，同时朝该玩家手牌方向8
南墙牌背：不旋转180，白色牌体边朝桌内
```

# 一、基础规则

## 1.1 牌

```text
108 张
万、条、筒三门
每门 1~9，每张 4 份
无花牌、风牌、箭牌
```

牌值字符串：

```text
wan1..wan9
tiao1..tiao9
tong1..tong9
```

鸡牌：

```text
幺鸡 = tiao1
八筒 = tong8
```

## 1.2 座位

固定罗盘座位：

```text
0 = 东
1 = 南
2 = 西
3 = 北
```

联机新玩家依次分配第一个空座：南 → 东 → 北 → 西。重连恢复原座位。

玩家出牌顺序为逆时针：

```text
东 → 北 → 西 → 南 → 东
```

牌墙物理顺序为顺时针：

```text
北 → 东 → 南 → 西 → 北
```

两者不是同一套顺序：前者是玩家行牌顺序，后者是牌墙取牌顺序。

## 1.3 分数

```text
每家初始 200 分
四家合计 800 分
允许负分
单机、联机都保留累计分数
```

## 1.4 基本行牌

```text
只能碰、杠、胡
不能吃
```

## 1.5 单机庄家

```text
单机第一局：本地玩家坐庄，即南位1
后续按连庄/换庄规则
联机第一局由房间规则决定
```

单机首局不使用东位0，固定由本地南位玩家先坐庄。

# 二、牌墙模型

## 2.1 两层 54 蹲

```text
54 蹲
一蹲 = 上层 poker[0] + 下层 poker[1]
北/南各 14 蹲
东/西各 13 蹲
合计 108 张
```

段长度：

```text
北墙：28 张（14 蹲）
东墙：26 张（13 蹲）
南墙：28 张（14 蹲）
西墙：26 张（13 蹲）
```

## 2.2 牌墙环 ring

`ring` 按物理取牌方向排列：

```text
ring[0..27]    北墙，左 → 右
ring[28..53]   东墙，上 → 下
ring[54..81]   南墙，右 → 左
ring[82..107]  西墙，下 → 上
```

四段：

```gdscript
SEG = {
    0: {"start": 0,  "len": 28, "seat": 3},  # 北
    1: {"start": 28, "len": 26, "seat": 0},  # 东
    2: {"start": 54, "len": 28, "seat": 1},  # 南
    3: {"start": 82, "len": 26, "seat": 2},  # 西
}
```

## 2.3 建立牌墙

入口：

```text
RoundState.start_round()
→ WallBuilder
```

流程：

```text
生成 108 张
Fisher-Yates 洗牌
按 28 / 26 / 28 / 26 切成四面墙
按物理取牌方向生成 ring
WallRing 保存 _ring、_drawn、_head、_tail、remaining
```

## 2.4 定庄与破墙

定庄：

```gdscript
dealer_seat = posmod(next_dealer_seat, 4)
```

单机第一局：

```text
next_dealer_seat = 本地玩家（南1）
```

联机第一局由抢庄决定：

```text
有人抢庄：只在抢庄玩家里随机
无人抢庄：四个座位随机
```

## 2.5 骰子破墙

红骰决定破墙侧，白骰不参与破墙：

```text
红骰 1/3/5 → 对家墙
红骰 4     → 上家墙
红骰 2/6   → 下家墙
```

逆时针顺序：

```gdscript
offset = 2 if die in [1, 3, 5] else (1 if die == 4 else 3)
target = posmod(dealer_seat + offset, 4)
```

破墙点：

```gdscript
break_index = segment.start + die * 2
```

因为一蹲是两张，`die * 2` 表示跳过 `die` 蹲。

设置牌头：

```gdscript
wall.set_head(break_index)
```

## 2.6 牌头与牌尾

牌头用于普通摸牌：

```text
从当前唯一未摸完墙段开始
每列先上层、再下层
北/东正向递增
南/西向物理小号方向推进
```

牌尾用于杠后补牌：

```text
最后一列上层
最后一列下层
前一列上层
前一列下层
...
```

牌头、牌尾共用 `_drawn`，不会重复摸同一张。

## 2.7 剩余量

```text
remaining = 108 - 已摸走张数
```

包括发牌、普通摸牌、杠后补牌。

翻鸡牌只是 `peek_head()`，**不摸走**，不扣剩余。

# 三、开局发牌

## 3.1 总量

```text
每家 3 轮 × 4 张 = 12 张
四家共 48 张
再按顺序每家 1 张，共 4 张
总计 52 张
每家 13 张
```

庄家第 14 张不在开局发牌阶段发。

## 3.2 发牌顺序

以庄家为起点，逆时针：

```text
庄家 → 下家 → 对家 → 上家
```

南庄示例：

```text
南 → 东 → 北 → 西
```

每轮每家拿两蹲（4 张）：

```text
第 c 列上层
第 c 列下层
第 c+1 列上层
第 c+1 列下层
```

两组两蹲可以跨墙，墙段是连续环，不能丢弃剩余一蹲。

## 3.3 发完后

```text
四家各 13 张
牌墙剩余 56 张
进入13张排序
排序完成后庄家摸第14张
庄家变14张，先出牌
```

庄家摸完后牌墙剩余 55 张。

# 四、普通摸牌与杠后补牌

## 4.1 普通摸牌

```gdscript
wall.draw_head()
```

每回合摸 1 张。

顺序：

```text
北墙：左 → 右
东墙：上 → 下
南墙：右 → 左
西墙：下 → 上
```

同一列永远先上层、后下层。

## 4.2 杠后补牌

```gdscript
wall.draw_tail()
```

从最后一列开始，按上层、下层、前一列上层、前一列下层。

杠后补牌不改变翻鸡位置；翻鸡仍看牌头下一张。

## 4.3 牌墙耗尽

```text
draw_head() 返回 ""
→ 荒牌/流局流程由 RoundState 处理
```

# 五、行牌与响应

## 5.1 当前回合

当前玩家摸 1 张后可以：

```text
自摸
暗杠
加杠
否则打出1张
```

## 5.2 响应优先级

```text
胡 > 杠 > 碰 > 下家摸牌
```

顺序：

```text
先开放胡牌窗口
所有可胡玩家处理完
再开放杠
杠家全部过牌
再开放碰
```

## 5.3 多人胡

同一张弃牌允许多人同胡。

## 5.4 过胡/过碰

```text
过胡：本人下一次摸牌前不能再胡
过碰：本人下一次摸牌前不能再碰同一张牌
```

## 5.5 报听后

```text
不能换牌
自动摸打
只打刚摸到的牌
摸到可自摸或别人点炮可胡时停下等待选择
```

# 六、碰与杠

## 6.1 碰

```text
手里至少2张相同牌
移除2张
与来源弃牌组成碰
碰牌者继续出牌
```

碰后不能立即打出刚碰进来的同一牌值。

## 6.2 明杠

```text
手里3张，别人打出第4张
从牌尾补1张
基础杠分4分
只在杠主与放杠者之间结算，方向按第6.6、11.4节
```

## 6.3 暗杠

```text
开局已有4张，第一次弃牌前可以暗杠
本回合摸到第4张，本次弃牌前可以暗杠
选择弃牌后，这张牌本局不能再暗杠
从牌尾补1张
基础杠分4分，付款资格按第6.6节；流局例外见第十二章
自己的视图立即显示暗杠牌面
其他玩家先看到反扣
完成后续两次出牌后公开翻开
暗杠获得胡牌通行资格
```

## 6.4 加杠

```text
已经碰过
之后摸到第4张才能加杠
宣告后先进入抢杠胡窗口
加杠成功从牌尾补1张
基础杠分4分，付款资格按第6.6节；流局例外见第十二章
可以被抢杠胡
```

## 6.5 杠后通行

```text
明杠后的弃牌：不开放普通小牌杠后通行
暗杠后的第一张弃牌：开放
加杠后的第一张弃牌：开放
```

## 6.6 杠分付款资格

胡牌局的一般规则：

```text
叫牌者暗杠/加杠：其他三家各付4，不要求付款者叫牌
明杠：只在杠主与放杠者之间结算基础4，完整方向见第11.4节
未叫牌杠主：不能收正分
未叫牌明杠：只向已叫牌的放杠者反付4
未叫牌暗杠/加杠：反向付给每位叫牌者
未叫牌玩家之间永远不互付
```

流局时优先按第十二章处理：部分叫牌流局，叫牌者之间不结杠分；四家全叫流局，本局所有收付为0。烧鸡者的收入和付款按第9.3节处理。

## 6.7 杠中鸡与基础杠分分开计算

胡牌局中，叫牌杠主的杠内鸡分如下：

| 杠牌种类 | 四张合计鸡分 |
| --- | ---: |
| 普通非鸡牌命中翻鸡范围 | 4 |
| 幺鸡或八筒，未翻成金鸡 | 8 |
| 幺鸡或八筒，翻成金鸡 | 16 |

上述鸡分参与全场两两鸡分比较，明杠也一样；杠基础4另按付款资格结算。杠内鸡分只计一次，不再向放杠者额外重复收取。

未叫杠主的普通翻鸡杠不产生翻鸡债务，也不记普通翻鸡负分；幺鸡/八筒杠中的鸡仍按8或16向每位叫牌者补付。基础杠分另算。流局不翻鸡，杠中幺鸡/八筒按8计算，不产生本局金鸡16或普通翻鸡4。

# 七、胡牌通行条件

普通弃牌胡牌，至少满足一项：

```text
胡牌玩家已报听
弃牌者已报听
这张牌是暗杠/加杠后打出的第一张
牌型为大对子或更高
小七对、龙七对
清一色或清一色特殊牌型
胡牌玩家自己有暗杠
胡牌玩家自己有加杠
当前是抢杠胡阶段
```

通行证：

```text
玩家自己有暗杠或加杠
明杠不算
```

普通小牌没有上述条件时只能自摸。

# 八、报听与胡牌费用

## 8.1 报听条件

```text
第一次摸牌后的出牌机会
打出一张即可听牌时可以报听
此前只允许暗杠
不能有碰、明杠、加杠
```

## 8.2 报听行为

```text
不能换牌
自动摸打
只打刚摸到的牌
可自摸/点炮时停下等待选择
```

## 8.3 报听费用

报听24包含基础4。以下金额均为单倍，鸡分、杠分和其他独立费用另算。

```text
没有牌型、干扣或大干扣时：报听胡牌24，不另加普通自摸4
有一项牌型、干扣或大干扣T时：T + 24 - 4 = T + 20
同时有牌型和干扣/大干扣时：各项叠加，所有内含的基础4只保留一个
```

付款人：

```text
自摸：其他三家各付适用于自己的胡牌费用
胡别人弃牌：只由放炮者付赢家的胡牌费用
```

赢家和放炮者都报听时，双方的报听项目合并，仍只保留一个基础4：

```text
没有牌型、干扣或大干扣：24 + 24 - 4 = 44
只有大对子14：14 + 24 + 24 - 4 - 4 = 54
还有其他可叠加项目时，按第8.5节统一去重
```

此处不另收杀报；自摸赢家已报听时，也不因付款者报听再加一份杀报。各类特殊费用是否适用，另按第8.6节判断。

## 8.4 杀报

赢家未报听时：

```text
报听者放炮：该报听者向赢家付杀报24
其他玩家自摸：每位报听付款者分别向赢家付杀报24
未报听的其他付款者不付杀报
```

杀报可与干扣、大干扣和牌型叠加，但这些项目内含的基础4只算一次。例如干扣14与杀报24合计34，不能只付24，也不能付38。

赢家也报听时，按第8.3节结算报听胡牌，不再额外收杀报。

## 8.5 叠加项目与基础4去重

先选定最高的一项计分牌型；干扣和大干扣二选一，大干扣替代干扣。选定的牌型、干扣/大干扣、报听或杀报可以叠加。

对每名付款人，分别合并适用于他的项目。若其中有N个包含基础4的项目：

```text
合并金额 = 各项目分值之和 - 4 × (N - 1)
```

普通自摸4不在这些含基础4的项目之外重复收取。鸡分、杠基础费、通行证4、抢杠12、杠后放炮17/21、杠开5、海底5属于各自独立款项，不因数值含4而按本公式扣除。

以下只算胡牌费用，鸡分、杠分和其他独立款项另算：

| 同时成立的项目 | 合并计算 | 金额 |
| --- | --- | ---: |
| 干扣 + 杀报 | 14 + 24 - 4 | 34 |
| 大干扣 + 杀报 | 24 + 24 - 4 | 44 |
| 大对子 + 杀报，不满足干扣 | 14 + 24 - 4 | 34 |
| 干扣 + 赢家报听 | 14 + 24 - 4 | 34 |
| 清一色 + 干扣 | 24 + 14 - 4 | 34 |
| 清一色 + 干扣 + 赢家报听 | 24 + 14 + 24 - 8 | 54 |
| 清一色 + 大干扣 | 24 + 24 - 4 | 44 |
| 大对子 + 赢家报听 + 放炮者报听 | 14 + 24 + 24 - 8 | 54 |

干扣例子均假设至少另一位叫牌者有鸡或有杠，因而不升级为大干扣。胡牌资格仍须满足第七章，不能用干扣或大干扣绕过胡牌通行条件。

## 8.6 独立胡牌费用

| 项目 | 条件 | 付款人 |
| --- | --- | --- |
| 普通点炮基础0 | 普通弃牌被胡 | 放炮者；牌型、报听、杀报等另算 |
| 杠后放炮17/21 | 暗杠/加杠后第一张弃牌被胡；放炮者叫牌为17，未叫为21 | 放炮者 |
| 通行证4 | 赢家自己有暗杠/加杠，以未报听、无计分牌型的普通小牌胡别人弃牌；抢杠不加此项 | 放炮者 |
| 抢杠12 | 抢加杠胡 | 被抢杠者 |
| 杠开5 | 杠后补牌自摸 | 其他三家各付5 |
| 海底5 | 牌墙最后四张中的任意一张自摸 | 其他三家各付5 |

符合条件的独立费用另付。杠后放炮与赢家通行证可叠加为17+4=21或21+4=25；杠开与海底可以同时成立。牌型、报听、杀报等再按各自付款人和基础4去重规则计算，一炮多响按每位赢家分别结算。

# 九、鸡牌、翻鸡、烧鸡

## 9.1 鸡牌

```text
一条（幺鸡）
八筒
```

分值：

```text
全场每种第一张打出：冲锋鸡4
之后打出：普通鸡2
手中保留：每张2
碰中、杠中：每张2
冲锋鸡被碰/杠后按普通鸡算，不再保留冲锋标记
```

## 9.2 翻鸡

只有胡牌局翻鸡，流局不翻。

```text
翻开牌头下一张
只 peek，不摸走
范围：本张、上一张、下一张
1 的范围：9、1、2
9 的范围：8、9、1
```

计分：

```text
普通翻鸡牌每张1
范围里的幺鸡/八筒为金鸡
普通金鸡4
冲锋金鸡8
其他两张仍按翻鸡1
```

叫牌者的手牌、碰中、杠中普通牌命中翻鸡时计分；未叫牌者的普通翻鸡不计收入，也不形成债务，普通翻鸡杠同样如此。未叫牌者手中的幺鸡/八筒不计正分；其出牌鸡、碰中鸡、杠中鸡仍按债务向叫牌者补付，翻成金鸡时使用对应的金鸡值。

## 9.3 烧鸡

被胡玩家烧鸡：

```text
抢加杠胡
暗杠后打出的牌被胡
加杠后打出的牌被胡
```

烧鸡只把自己的鸡分归0：

```text
自己的手牌鸡、碰中鸡、杠中鸡、出牌鸡、翻鸡不计收入
自己的杠收入不计
仍必须赔付赢家的鸡分、杠基础分、放炮分
抢杠/杠后放炮等非鸡分照付
```

# 十、牌型分

```text
普通自摸       4
干扣          14
大干扣        24
报听胡牌      24
大对子        14
大对子单吊    24
小七对        24
龙七对        44
清一色        24
清大对        34
清七对        44
清单吊        54
清龙七对      64
```

规则：

```text
大对子、七对、清一色及其特殊组合牌型只取最高一项，不重复叠加组成牌型
干扣与大干扣二选一，可与选定的牌型、报听或杀报叠加
报听24不属于牌型分，但内含基础4；叠加时按第8.5节只保留一个基础4
```

## 10.1 干扣与大干扣的成立条件

干扣14适用于有合法胡牌资格的胡牌或自摸玩家。本人须同时满足：

```text
没有幺鸡、八筒计分来源，含手牌、碰中和保留的出牌鸡
翻鸡没有命中自己的手牌或固定碰组，本人鸡分为0
没有任何明杠、暗杠或加杠
```

普通非鸡碰组本身不阻止干扣；碰组含鸡或命中翻鸡时，因鸡分不为0而不成立。是否报听、有无其他计分牌型，均不单独排除干扣。

大干扣24先满足本人的干扣条件，再逐一检查其他三家：

| 其他玩家状态 | 对大干扣的要求 |
| --- | --- |
| 未叫牌 | 在大干扣资格判断中按鸡分0处理，其手中鸡、鸡分债务或杠不阻止大干扣 |
| 已叫牌（含其他赢家） | 鸡分为0：无手中、碰中、保留出牌鸡，也没有命中翻鸡；并且没有任何杠 |

三家均满足对应条件时，用大干扣24替代干扣14，不把两项相加。未叫牌者在本项判断中按0处理，不等于免除其本来应向叫牌者支付的债务。

## 10.2 特殊牌型

```text
龙七对必须由和牌张凑成第四张
手里本来四张、胡别的牌，只算七对
大对子单吊、清单吊要求已有四组固定碰杠，胡牌前手中只剩一张单牌
```

# 十一、计分与付款

## 11.1 个人分

个人分用于展示自己产生的计分项目，不等于本局累计分数的净变化，也不能把四人的全部个人分直接相减代替付款流水。

叫牌者：

```text
手里鸡 + 保留的出牌鸡 + 碰里鸡 + 杠里鸡 + 翻鸡
+ 牌型分 + 杠基础分
+ 报听分 + 胡牌基础分
```

其中胡牌费用先按第8.5节合并、去重；杠基础分按第6.6节的实际付款资格统计。未胡的叫牌者不因潜在牌型收胡牌费，流局查叫补付另按第12.3节。

未叫牌者：

```text
-（打出的鸡 + 碰里的鸡 + 杠基础分 + 杠里鸡）
```

未叫者的手中鸡和普通翻鸡不列入此负分；普通翻鸡杠也不额外扣翻鸡4。未叫者的明杠基础4仅作为与已叫牌放杠者有关的债务，暗杠/加杠基础4则向每位叫牌者补付。明细与实际付款必须使用同一债务口径。

鸡基础值：

```text
普通鸡：2/张
金鸡：4/张
冲锋鸡：4（翻中8）
杠中鸡：8（翻中16）
翻鸡普通牌：1/张
```

胡牌基础：

```text
自摸4
干扣14
大干扣24
点炮0
杠后放炮17（放炮者已叫）/21（没叫）
抢杠12
通行证4
杀报24
杠开5
海底5
```

## 11.2 两两相对分

先按两人的叫牌状态比较鸡分，再加入各自应付的独立款项，最后只保留两人之间的一笔净收付：

| 两人状态 | 鸡分结算 |
| --- | --- |
| 双方叫牌 | 鸡分少的一方向多的一方支付差额，含杠中鸡与普通翻鸡杠的鸡分 |
| 只有一方叫牌 | 未叫者支付叫牌方鸡分，并补付自己应付的出牌鸡、碰中鸡、杠中鸡债务 |
| 双方未叫 | 永远不互付 |

杠基础费、实际胡牌者的牌型/干扣/大干扣、报听、杀报及特殊胡牌费，按各自付款人加入这两人的流水，不能一律作为全场分差处理。付款人适用的胡牌项目先按第8.5节去重。流局的付款范围以第十二章为准。

最后将A应付B与B应付A的款项相抵，每对只形成一个净额；四家净变化之和必须为0，累计总分保持800。

## 11.3 特殊款项

```text
牌型分：点炮只由放炮者付给赢家
报听24/20：点炮只由放炮者付
抢杠12：只由被抢杠者付
杠后放炮17/21：只由放炮者付
通行证4：只由放炮者付
杀报24：赢家未报听时，由报听放炮者或被自摸的每位报听者各自支付；基础4按第8.5节去重
明杠基础4：只在杠主与放杠者之间结算，方向按第11.4节
杠中鸡（含明杠）：参与全场两两鸡分比较，基础4另算
```

暗杠、加杠基础4：

```text
胡牌局叫牌杠主：其余三家各付一份
未叫杠主：反向付给每位叫牌者
流局：叫牌者之间不互付；四家全叫时本局全部0
```

## 11.4 明杠最后算

明杠基础4只比较杠主与放杠者，不混入对其他两家的基础杠费。杠中鸡已经按第6.7节参加鸡分结算，不在此重复收取。

| 杠主状态 | 放杠者状态 | 胡牌局基础杠费 | 部分叫牌流局基础杠费 |
| --- | --- | --- | --- |
| 叫牌 | 叫牌 | 放杠者付杠主4 | 0 |
| 叫牌 | 未叫 | 放杠者付杠主4 | 放杠者付杠主4 |
| 未叫 | 叫牌 | 杠主反付放杠者4 | 杠主反付放杠者4 |
| 未叫 | 未叫 | 0 | 0 |

四家全叫流局，本局所有收付为0，不再按胡牌局矩阵收明杠4。烧鸡者不收收入，仍按第9.3节承担对其他玩家的应付款。

## 11.5 倍率

倍率在结算最后统一乘一次，覆盖所有收付：

```text
鸡分（含金鸡、冲锋鸡、杠中鸡、翻鸡）
自摸/干扣/大干扣
牌型分
杠基础分
报听费
杀报费
抢杠费
杠后放炮费
通行证/杠开/海底
```

红白骰同点：

```text
本局所有收付 ×2
```

与流局后带入的倍率共用，最高×2，不叠加×4。所有流局均使下一局为×2；只有完成胡牌局后，下一局恢复×1。

## 11.6 两人付款核对例

以下均为单倍，A、B未报听；没有列出的计分项不计入例子。

### 例1：未叫者的普通翻鸡杠不产生翻鸡债务

```text
A自摸：123万｜234条｜456筒｜111条｜99筒
B暗杠：5555万
B手牌：1、3、8、9万；2、5、8条；1、4、7筒（未叫）
翻牌：六万，范围五、六、七万
```

A普通自摸4，三张幺鸡6；B未叫，向A反付暗杠基础4。B杠中的普通翻鸡4不形成债务：B付A = 4 + 6 + 4 = **14**。B这一组杠的负分明细只记基础−4，不记为−8。

### 例2：部分叫牌流局，叫牌者之间不结杠分

```text
A暗杠：5555万
A手牌：123万｜234条｜123筒｜9万（听九万）
B手牌：678万｜567条｜456筒｜999筒｜9条（听九条）
另外两家未叫，牌墙摸完流局，不翻鸡
```

A、B均叫牌，两人之间不结鸡分差或杠基础分，净付款 **0**。A的暗杠换成加杠，结论相同；另外两名未叫者的补付款分别计算，不改变A、B这一对的0。

### 例3：四家全叫流局，明杠也不付4

沿用例2中A、B的手牌，A的五万杠改为明杠，来源是B打出的第四张五万；另外两家也叫牌。四家全叫流局，本局全部不计分，因此B付A **0**，不再另付明杠基础4。

# 十二、流局、包牌、下一局庄家

## 12.1 流局

```text
牌墙摸完无人胡牌
不翻鸡
不产生本局金鸡或普通翻鸡分
所有流局均使下一局所有收付×2，连续流局仍封顶×2
```

## 12.2 四家都叫

```text
本局所有分项和收付均为0，包含明杠、暗杠、加杠基础分与杠中鸡
下局所有收付×2
连续流局倍率仍封顶×2
当前庄家连庄
```

## 12.3 包牌

有人未叫牌，未叫牌者向每位叫牌者补付：

```text
双方已打出的幺鸡/八筒
双方碰中的幺鸡/八筒
应付的杠基础分、杠中鸡，按叫牌资格分别结算
叫牌者能听成的最高牌型分；没有牌型则付4
```

牌型补付替代荒牌基础4，不额外叠加。例如听清一色时收24，不收28；听多张时按各张成胡后的实际牌型取最高值，龙七对仍须由该假定胡牌张凑成第四张。此处是流局查叫，不另计报听、杀报、干扣或大干扣胡牌费用。

流局不翻鸡，普通出牌鸡按2、冲锋鸡按4、碰中鸡每组6、杠中鸡每组8计算；没有本局金鸡或普通翻鸡。全场每种首张鸡是否仍归本人，按碰杠后的实际归属判定。

```text
叫牌者之间不补鸡分差，也不结明杠、暗杠、加杠基础分
手中鸡不加入本次补分
未叫牌者不因手中鸡产生正分
未叫牌者之间不互付
四家均未叫时没有收款人，本局所有收付为0，下局仍×2
```

对一名叫牌者与一名未叫者，暗杠/加杠基础4由未叫者付给叫牌者：未叫者自己的杠基础4反向付，叫牌者自己的杠基础4正常收。明杠只比较杠主与放杠者，方向见第11.4节。全部查叫补付汇总后，再应用本局倍率一次。

## 12.4 下一局庄家

```text
有人胡：胡牌者中本局净得分最高者当庄，并列随机
流局且有人未叫：未叫牌者中失分最多者当庄，并列随机
四家都叫流局：当前庄家连庄
```
