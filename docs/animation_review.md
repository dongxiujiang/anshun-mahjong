# 麻将动画复核与真实桌面差异

本次复核覆盖 `RoundState` 的视觉事件、`RoundPresentation` 的事件编号、牌桌动画控制器、临时动画层、`TileView`、回合指示灯、按钮和结算层。牌局状态仍由权威端推进；动画只消费事件，不会改变牌墙、手牌、分数或回合权限。

## 事件链

```text
RoundState
  └─ RoundPresentation.emit_event()
       └─ GameTable._on_visual_event()
            └─ TableAnimationController（去重、定位、发牌队列、理牌阶段）
                 └─ TableAnimationLayer（临时牌、Tween、落桌、抛物线理牌）
                      └─ TileView（牌面、牌背、选中/胡牌高亮）
```

权威事件带 `session + id`，控制器按局去重；没有 session 的事件只用于本地截图/预览，使用独立的预览游标，不会污染联机事件编号。这样可以在审查某个动作后继续接收真实牌局的低编号事件。

## 和真实麻将桌的差异

| 动作 | 原来的表现 | 现在的表现 | 真实桌面的对应关系 |
| --- | --- | --- | --- |
| 掷骰 | 一颗骰子在中心匀速旋转并改变点数 | 保留项目规则的一颗骰子，增加落点弧线、缩放和最终停留 | 本项目规则是单骰破墙；加入第二颗骰子会改变破墙规则，所以没有擅自改规则 |
| 起手发牌 | 牌从中心直线移动，四张同时到位 | 开局手牌区先为空；骰子后按三轮四张、最后单张逐墩落入未排序手牌，四张有 35ms 错峰，带抛物线、转向和落桌回弹；全部落桌后再做一次抛物线理牌 | 对应真人一次推一墩四张牌；庄家最后一张单独进入，之后把散牌推开、互相插入排序 |
| 摸牌 | 从中心直线进入摸牌位 | 从该座位的牌墙位置进入，牌背按信息权限显示，落位有轻微回弹 | 对应从牌头/牌尾抽牌；视觉不泄露其他玩家牌面 |
| 弃牌 | 牌从手牌到河牌的直线移动 | 保留精确重复牌身份，从被点击的手牌位置飞到河牌，带轻微抬升和落桌 | 对应拿起、放到弃牌区；不再从错误的摸牌位起飞 |
| 摸打排序 | 状态刷新后整排瞬间替换 | 暂存旧手牌，弃牌后让相邻牌滑开，再把摸牌插入排序位置 | 对应真人把牌推开留缝、补回手牌 |
| 碰/明杠 | 所有牌从中心同时出现 | 被领取弃牌从原河牌位置进入，手中相同牌从旧手牌位置进入；明杠来源牌落到横牌槽 | 对应拿弃牌和手牌组成面子 |
| 暗杠/加杠 | 只在最终牌组位置翻转或移动 | 暗杠保持牌背，后续翻牌使用独立的横向翻面；加杠沿原碰牌组完成 | 保留暗牌信息与加杠来源，避免客户端提前看到秘密牌 |
| 报听/胡牌 | 文字标签淡入淡出 | 标签仍保留，但牌的最终高亮由 `TileView` 呼吸动画维持 | 对应桌面上的动作提示与和牌牌面强调 |
| 操作时序 | 只锁定本地摸牌 | 任何飞行、落桌、碰杠或开局队列期间都锁定操作 | 真人不会在牌尚未落桌时抢先摸打或响应 |

## 关键实现

- `TableAnimationController._source_for_event()` 为发牌/摸牌提供四个牌墙起点；弃牌和碰杠继续使用旧牌节点的精确位置。
- `TableAnimationController._hand_snapshot()` 在权威状态刷新前保存旧手牌位置；`meld_hand_snapshot` 让碰杠动画可以从旧手牌取牌。
- `TableAnimationLayer._quad_bezier()`、`_smoothstep()` 和按牌错峰的 Tween 模拟拿牌、抬牌、移动、落桌四个阶段。
- 开局不再预先创建完整排序手牌，也不使用遮罩盖住未发牌；`PlayerTileAreas` 只渲染 `_dealt[seat]` 张，发牌 Tween 完成后提交这一墩。
- `TableAnimationController._sort_destinations()` 在最后一张落桌后按真实牌值建立目标槽位，`TableAnimationLayer._sort_hand()` 直接移动现有牌节点，用错峰抛物线完成理牌。
- `PlayerTileAreas` 为每张面子牌记录 `meld_slot` 与 `meld_sideways`，因此明杠来源牌会进入真实的横放槽位。
- 开局权威等待时间把每墩牌的错峰纳入计算，避免逻辑先解锁而动画还未落桌。

## 尚未等同于真实摄像机的部分

牌桌仍是 2D `Control` 渲染，没有真实 3D 透视、手指/手臂遮挡、牌墙逐层搭建和材质反射；项目也把牌墙隐藏在规则层，只用其位置驱动抽牌动画。若要进一步接近录像级效果，下一步应把牌和牌墙迁移到 2.5D/3D，加入接触阴影、牌桌碰撞声与落牌时刻同步，并把摄影机视角变化作为单独的表现层处理。
