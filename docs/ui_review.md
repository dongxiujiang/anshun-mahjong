## 动效设计与边界

- 骰子有真实点数、滚动旋转和落定，结束显示权威端给出的数值。
- 每次两墩四张依顺时针发入各家的实际手牌位置；末尾单张继续使用真实发牌记录。开局可跳过。
- 普通摸牌、杠后补牌飞入独立摸牌区。其他玩家只出现牌背，不通过动画暴露手牌。
- 出牌从旧手牌位置飞向实际弃牌或鸡牌位置，同时由手牌尺寸平滑缩至弃牌尺寸。冲锋鸡按目标布局横放。
- 碰、明杠、暗杠、加杠有牌组入场与短暂文字反馈；明杠仍按来源横放，碰牌三张竖放、暗杠和加杠四张竖放。
- 暗杠保持反扣，下一轮本人出牌后才播放翻面。加杠只有实际完成时才播放入场，被抢时不会先展示完成的杠。
- 报听、胡牌、自摸有短暂文字反馈。最终胡牌张有轻微呼吸高亮，结算在牌桌动作播放完后展示。
- 按钮按下轻缩、松开缓动恢复。弹窗采用短暂淡入与 12 像素滑入，避免长时间挡住操作。
- 逻辑数据立即完成、界面异步播放；开局 52 张牌立即生成，权威端保留统一开局等待，之后再摸庄家的第 14 张并开启行动。客户端仅锁住本地输入，不用动画回调推进权威回合。普通 headless 回归跳过视觉等待，专用服务器保留真实开局等待。
- 普通联机快照不再取消正在播放的动作；事件按会话和编号去重。重连时取消 Tween、恢复临时隐藏的牌，并用下一份快照建立基线，跳过掉线期间旧动作。

## 调整入口

| 文件 | 内容 |
| --- | --- |
| `scripts/ui/UiStyle.gd` | 共用颜色、圆角、阴影、按钮和输入框样式，以及 Android 安全区 |
| `scripts/ui/UiMotion.gd` | 按压反馈、弹窗淡入滑入，以及中途取消恢复 |
| `scripts/ui/table/TableUiConfig.gd` | 牌桌尺寸、间距、字号、按钮、动效基础时长 |
| `scripts/ui/table/TableAnimationController.gd` | 事件去重、顺序、实际牌位、临时遮挡、开局跳过与取消 |
| `scripts/ui/TableAnimationLayer.gd` | 临时牌、移动、旋转、翻面和文字动效 |
| `scripts/ui/DiceView.gd` | 程序绘制的骰子 |
| `scripts/ui/TileView.gd` | 选中抬起、热区、高亮、胡牌呼吸效果 |

- 新增 `ui_presentation.gd` 34 项检查，涵盖发牌顺序、秘密牌隐藏、公开牌显示、暗杠亮牌时机、快照去重、重连基线、热区、实际牌位和小屏弹窗；已加入普通提交的 GitHub 快速检查。

## 2026-10-14 牌桌操作与结算准备修订

- 顶部设置入口使用独立 144×72 视觉尺寸，完全位于页头内，不再复用 177×126 的操作按钮。不可见热区向左、下扩大至 168×112，仍位于画布内；碰杠鸡牌布局避开整个热区，实际 GUI 命中扩大热区的测试通过。
- 移除出牌按钮，手牌与摸牌短按松手一次出牌。滑动防误触、原生触控与模拟鼠标去重、合法操作校验同时保留。只有报听、自摸、碰杠胡等必要选择显示操作按钮；结算通过原有卡片切换入口查看，不再多放一个大号结算按钮。
- 骰子滚动改为 1.2 秒，最终点数保持 0.5 秒；16 次发牌各 0.16 秒。开局采用统一节奏，日常摸打仍使用快慢设置。发牌或自己的摸牌未播完时，点牌与直接提交入口均被锁住；退出或重新开局会使旧计时失效。
- 结算明细高度略收，底部独立显示四家准备卡片、准备人数、等待提示与大号准备/取消按钮。长昵称截断，不遮挡按钮；全部准备后保持原有 1 秒倒计时，准备同步不重建卡片、不抢回已隐藏的结算。
- 全部 36 套回归中旧设置尺寸测试按本轮要求修订后通过，受影响交互、布局、结算和大厅流程已再次复测。50 局对战为 45 胡、5 流局、32 自摸，牌数守恒；3,792 种结算独立核算与逐家付款检查通过。
- 多进程局域网、在线房间、四真人准备/取消倒计时及重连均通过。新增准备卡片边界与四人确认显示检查，覆盖每个玩家视角。
- 真实 OpenGL 窗口截图保存在 `build/ui_review/table_controls/`，覆盖 1280×720、960×540 和 2400×1080；`capture_table_controls.gd` 检查完整开局、固定骰子停留、慢速摸牌输入锁与真实触控事件。Android 真机仍未连接，本轮验证不等同于真机测试。

## 2026-10-14 中央信息区修订

- 隐藏东、南、西、北以及“你、上家、对家、下家”等桌面标签；单机只看四个累计分数，联机在各自分数上方显示输入的昵称，AI 显示“人机”。昵称过长会省略并保留完整 tooltip。

- `CenterTurnIndicator.gd` 使用一层轻量 Shader 绘制边缘散射光，按本地视角把当前出牌方映射到对应边；切换用 0.22 秒缓动，非出牌响应窗口、发牌和结算自动熄灭。
- `tests/center_dashboard.gd` 覆盖四种本地视角、四个当前出牌方、联机昵称/人机标识、长昵称截断、庄家徽标、响应/发牌/结算熄灯、960×540 与 2400×1080 尺寸，共 245 项断言；真实窗口截图位于 `build/ui_review/center_dashboard/`。
- 真实窗口另检查了每条边两端的边缘亮度和外侧柔光衰减，共 261 项断言通过；受影响布局、交互、结算及同步回归通过，15 套规则/计分/音频/UI 检查全部通过，其中新跑 24 局对战（21 胡、3 流局、16 自摸），牌数守恒。此前 50 局结果属于前一轮验证。
