# V1.6.30

- 调整自己的碰杠与幺鸡、八筒摆放，减少手牌遮挡，并让明杠的来源横牌紧贴牌组。
- 修复碰杠、幺鸡落桌及自己的摸牌、出牌动画衔接，避免动画前后突然跳位。
- 新增碰杠或鸡牌时，保留仍有空间的旧牌位置，减少已落牌突然换位。
- 修复满行弃牌暂时遮挡邻家牌面，以及出牌落桌、被碰杠取走时的跳位。
- 将最新弃牌三角标记放在各方位弃牌区外侧，避免挡住相邻牌面。
- 增大底部操作按钮的触控范围，优化排序说明和分组线的位置，保留手牌牌面可读性。
- 结算时为本家一侧的翻鸡牌留出空间，翻牌过程和落定后的牌面均可见。
- 提前显示点牌反馈，处理拖动取消、回合切换及退出时的输入，减少误触和重复动作。
- 让开局骰子声音跟随实际画面出现，并修复重新加入开局房间时遗留的等待状态。
- 增加安卓 x86_64 原生支持，供兼容设备和模拟器直接运行；保留 ARM64 支持，并压缩安装包中的原生库。

- 开局使用固定两层牌墙；普通摸牌、杠后从整圈牌尾补牌、结算翻鸡均按实际槽位显示。
- 翻鸡、鸡分和杠分动画不再给桌面计分牌加金色描边。
- 结算得分行补齐本人流局碰中幺鸡、八筒；三家共同适用的项目优先且不加括号，部分适用时标明上／对／下。
- 修正死叫的结算资格、首张幺鸡或八筒被胡的鸡分归属，以及报听后只能打出实际摸到的牌。

本次使用完整 Android 安装包；联机结算由同版本服务器处理。
