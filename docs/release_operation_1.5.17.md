# 1.5.17 发布与部署记录

版本：`1.5.17`

构建日期：2026-10-25

## 本版内容

- 「AI帮打」更名为「AI教学」；
- AI 教学开关在非自己回合可以直接打开，不再弹出“当前不是你的出牌回合”；
- 每次自己摸牌出牌自动调用教学，使用当前 AI 强度；
- 教学提示在出牌、响应或结算开始前自动消失；
- 可以碰/杠/胡时，AI 教学同时提示建议动作；
- 碰杠/鸡牌改为堆叠模式：
  - 冲锋鸡单独放最底行；
  - 普通鸡在上方四张一行，超出继续向上；
  - 每个碰、杠各占一行；
  - 组与组固定小间距，不再分散到远处。
