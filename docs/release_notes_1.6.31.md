# 安顺麻将 1.6.31

本次更新优化安卓牌桌布局及相关动画。

- 自己和对家的普通弃牌贴紧排列，保留既有行列容量和前后遮挡关系。
- 各家的幺鸡、八筒与碰杠按首次公开顺序，在手牌前优先居中；普通弃牌不移动已有公开组。
- 明杠统一四个方位的来源摆法：上/下家供牌的横牌与三张同排、位于对应侧；对家供牌的横牌在三张朝桌心一侧居中。暗杠、补杠四张连续排列。
- 移除排序、上一种/下一种、恢复按钮，以及排法描述和手牌下金线；保留自动理牌。
- 摸打手牌和摸牌底部对齐，修正开局发牌落点；补杠先让位、再让第四张入位。
- 姓名分数固定在各家安全位置；结算按钮预留空间，避免遮住牌面。满桌操作条按可用空位摆放。
- 保留自己的鸡牌得分明细，全部对手适用的项目不加方位括号，部分对手适用时显示对应方位。

本次未修改游戏规则、牌墙取牌顺序、合法操作、AI 决策或计分逻辑。原版 1.6.30 可在游戏内下载约 354 KiB 热补丁，重启生效；也可使用沿用正式签名的 [完整 APK](https://mj.dongxiu.fun/updates/anshun-mahjong-1.6.31.apk) 覆盖更新。已发布至 [GitHub V1.6.31](https://github.com/dongxiujiang/anshun-mahjong/releases/tag/V1.6.31)。具体布局要求、验证范围及剩余限制见 [牌桌布局规范](牌桌布局规范.md) 和 [1.6.31 验收记录](验收记录_1.6.31.md)。本次已验证安卓模拟器两种尺寸及实际整局，未测试 ARM64 实体手机，不据此宣称语音或性能改善。
