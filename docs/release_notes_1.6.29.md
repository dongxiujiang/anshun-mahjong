# V1.6.29

- 放大其他玩家的手牌、普通弃牌和碰杠牌，调整牌间贴合、行距和四家区域避让，提升手机横屏辨认度。
- 优化深青绿色桌布、胡桃木边框和周围背景，减少纹理干扰，让象牙色牌面更清晰。
- 缓存碰杠区域的布局计算，复用玩家信息与回合标记，减少重复刷新和内存分配。
- 仅有自己和人机时不启动实时语音服务；有其他在线玩家后自动恢复，减少无用的后台音频处理。

- 保留冲锋幺鸡的身份，修复结算横牌显示；调整普通弃牌位置和底部操作按钮的大小、间距。

本次为完整 Android 安装包，可覆盖安装并保留原有设置。玩法、计分和联机协议保持兼容。
