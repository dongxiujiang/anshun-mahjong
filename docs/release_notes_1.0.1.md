# 安顺麻将 1.0.1 · 手机热点联机修复

- 修复手机给电脑开热点时，手机可能搜索不到电脑房间的问题。
- 自动按 Wi-Fi 和热点网卡搜索，增加定向广播、局域网单播扫描和房主主动通知。
- 支持广播被屏蔽、手机热点网卡未暴露给应用的发现方式，仍无需输入 IP。
- 保留房间号、选座、换座、准备、开局及游戏规则。

这是基于 V1.0.0 正式安装包的小版本补丁。电脑和手机都在主菜单「检查更新」下载并重启生效，无需重新安装。

使用方法：手机开热点 → 电脑连接该热点 → 电脑在「局域网」创建房间并保持等待 → 手机打开「局域网」，等待自动出现房间后加入。首次完整扫描单个网段约需数秒，多网卡时可能更久。
