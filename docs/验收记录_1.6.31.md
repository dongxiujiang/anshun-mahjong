# 1.6.31 牌桌布局验收记录

日期：2026-11-20；当前状态：最终安卓验收及公开更新链路通过，已发布 [V1.6.31](https://github.com/dongxiujiang/anshun-mahjong/releases/tag/V1.6.31)。本记录为发布后的文档补记，记录已测试的运行源码 `2cb6647f24f012c812b6a3e7539eaad0c2a012d4`，不代表重新构建。

需求依据：[牌桌布局规范](牌桌布局规范.md) L01–L11。正式完整包为 Android 1.6.31、versionCode 91、安装基线 `1.6.31-native1`；供原版 1.6.30 使用的累计补丁基线为 `1.6.30-native1`。

## 1. 改动范围

- 南北弃牌按模型宽度贴近；公开鸡牌与碰杠按首次公开顺序居中，普通弃牌不改变已有公开组姿态。
- 侧来源明杠横牌与三张同排，位于对应侧；对家来源横牌在三张朝桌心一侧居中，所有观察视角一致。暗杠和补杠四张连排。
- 删除整理工具栏、排法文字与金线，固定四家名分；摸打手牌贴底，开局落点一致，补杠先让位再入位。
- 结算按实际下一局/准备/返回按钮预留空间；公开牌与结算面板、牌河、手牌和名分避让。阶段已结算但最后动画尚未结束时保留原公开牌姿态，不提前重排。
- 保留上一轮自己的鸡牌得分项修复；没有修改牌墙、合法操作、AI 决策、玩法或结算金额。

## 3. 环境与证据

- 实际逍遥：MEmu_2，Android 9/API 28，x86_64，1280×800、2400×1080 两种尺寸，原生后台模式启动，串口 127.0.0.1:21523。
- 首轮 QA APK 在逍遥以 Android + GL Compatibility 真实渲染完成 6 组、59,535 项断言和 28 张截图。该版本随后被上述进一步修复替代，**其结果不作为最终候选通过的证明**。
- 最终 QA 两种尺寸各完成 7 组、69,877 项断言、42 张非空截图，错误为 0；来源、底部按钮及真实回放画面已审看。重复牌密集 fixture 只作为压力场景。正式 APK 与 QA 的 1,294 项运行载荷一致，其中 7 个场景仅归一化构建生成的节点 ID。
- 原版 1.6.30 APK 加载补丁后完成实际整局 43 次操作，分差 `[6,-26,6,14]`；正式 1.6.31 APK 完成实际整局 46 次操作，分差 `[-30,-18,20,28]`。两局总分均为 800，脚本错误为 0；正式包冷启动通过，原有两份牌谱字节保持不变。补丁下旧牌谱记录器仍写基础版本 1.6.30，实际生效版本由界面 1.6.31 和 active 补丁散列另证，未修改牌谱。
- 本地原始回归证据：工程内 `build/release-layout-1631-evidence/`；最终构建和发布证据：外层 `../release-layout-1631-evidence/`，包括 `build/final-android-acceptance.json`。验收后 MEmu_2 已停止，其他实例未改动。签名凭据不入库。

## 4. 通过门槛

1. 最终源码规则门禁通过，UI 测试迁移有逐项理由；完整回归的原始结果及修复后的专项分别记录，图形和必要联机回归无真实脚本或引擎错误。
2. 从最终提交构建正式签名 APK 和独立 QA 包，在逍遥测试布局、开局、摸打、补杠、结算按钮与三种供牌来源；逐张审看实际截图。
3. 正式 APK 实际安装启动，完成单机实际对局与退出重启检查；不把 QA 包运行当成正式安装体验。
4. 发布前核对版本、正式证书、源码 SHA、包内来源和散列；保留可用的新热更新基线。
5. GitHub 与自建两份签名更新清单及 APK 回读匹配，房间规则服务不重启、不切换版本。

未测试 ARM64 实体手机；真机声学、持续网络/语音质量及性能测量不在本次已完成验收内。
