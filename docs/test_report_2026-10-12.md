## 修复内容

- AI 新增代码的局部变量类型推断错误，之前会导致脚本加载失败后测试一直等待。
- 断线玩家重新接回操作权后，旧的人机延迟动作仍会执行；现在会校验原操作提示及控制者，并立即恢复人类操作提示。
- 重连收到座位分配但尚未收到最新牌局时可能提交旧操作；现在等待有效的新快照。
- 断线测试中缺失准备步骤、读取不存在的手牌字段及无期限等待的问题。
- 测试入口增加实际时间限制、错误检测、日志和失败时清理自身子进程；AI 和重连专项已注册到常规检查。

## 复现

在工程目录运行，替换 Godot 的实际路径：

```powershell
python -X utf8 tests/run_suites.py --godot "C:/path/to/Godot.exe"
python -X utf8 tests/run_network.py --godot "C:/path/to/Godot.exe"
python -X utf8 tests/run_reconnect.py --godot "C:/path/to/Godot.exe"
```

常规检查日志位于 `build/test_results/`；联机日志位于 `build/`，例如 `reconnect_host.log`、`reconnect_client.log` 和 `ready_player_0.log`。完成标记、退出码和 Godot 错误输出共同判断通过，超时不会计为通过。

## 验证范围

联机验证在 Windows 本机多进程及本机服务之间进行，尚未覆盖 Android 真机、手机热点隔离、真实公网延迟、杀掉应用后的恢复或房主退出后的恢复。

当前 AI 使用向听、有效进张、牌形及公开牌河/副露风险评估，本轮检查功能与稳定性，未做新旧 AI 对抗胜率实验，也未实现完整 MCTS。
